# 分类导航与加载

电影、剧集、动漫、综艺及自定义分类共用 `/douban`。同一页面内切换分类使用 Next.js 支持的 History API，立即更新地址、标题和选中项，避免为纯客户端筛选等待服务器路由请求。每个分类拥有独立的组件生命周期，切换和浏览器前进后退都会重置筛选并取消旧请求。

侧栏、底栏及首页分类入口使用 `NavigationLink`。跨页面跳转显示进度；软导航八秒未完成时尝试普通页面导航。保留链接地址和修改键打开新标签页的行为，不在导航完成前提前修改选中项。

`useCategoryFeed` 统一管理首屏与分页：过期结果、错误和取消请求不能修改新分类；滚动回调同步加锁；分页失败保留现有内容，手动重试同一页。番剧日历不分页。首屏失败显示重新加载按钮，再次点击当前分类也可重试。

豆瓣各数据通道与番剧日历均支持取消请求，十五秒超时覆盖响应头和 JSON 正文读取。分类请求不写入 KV 或 D1。

回归验证覆盖快速连续切换、过期响应、失败重试、分页并发和失败后重试、动漫星期切换、前进后退、损坏的侧栏本地设置、桌面与移动尺寸，以及服务器路由请求停滞后的导航恢复。
