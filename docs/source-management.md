# 视频源、直播源编辑与搜索恢复

管理面板的视频源和直播源均支持添加、编辑和备注，包括从配置文件或订阅导入的源。编辑保留 Key，避免改变收藏、播放记录和用户权限引用的标识。配置导入的源仍通过配置文件管理删除。

视频源可编辑名称、API 地址、Detail 地址和备注；直播源可编辑名称、M3U 地址、节目单地址、User-Agent 和备注。备注支持换行，最多 2000 个字符。旧配置没有备注时显示「暂无备注」，无需数据库迁移或增加 Cloudflare 绑定。

手动编辑会保存 `overridden: true`，后续订阅整理保留本地编辑、备注和禁用状态。未编辑的订阅源继续跟随订阅更新。所有内容仍保存在现有管理员配置中。

源操作按顺序提交，快速重复点击同一操作只发送一次。保存期间显示「保存中」，成功后使用服务端返回的源列表更新页面；失败时保留原状态并显示错误。可拖动行使用稳定组件，父组件更新不会重建操作按钮。桌面操作列固定在表格右侧；手机采用卡片，地址和备注可换行。

共享数据库配置每次读取最新内容，不再依赖 Worker 实例内永久有效的配置副本。播放直播时只读取和缓存频道，不回写管理员配置；手动或定时刷新频道数会在下载结束后读取最新配置，只合并未被禁用、删除或修改地址的源的频道数。保存直播源无需等待下载 M3U 和节目单，首次播放或点击「刷新直播源」时更新频道。

搜索表单提供明确的「搜索」按钮，也支持回车、历史和建议词。再次提交同一关键词会重新搜索，切换关键词会关闭旧连接并取消旧请求，旧响应无法覆盖新结果。中文输入法确认候选词不会提前触发搜索。

流式搜索连接失败或无响应时，自动回退普通搜索。请求设置超时，并提供错误提示和重试按钮；没有启用源时，流式接口也会正常发送完成事件。个性化搜索响应不进入浏览器或 CDN 公共缓存。采集源缓存包含 API 地址和名称，编辑后不会继续命中旧地址结果；短暂失败仅缓存 10 秒。API 原有查询参数和带签名参数的 M3U8 地址均保留。

回归覆盖配置同步、导入源覆盖、备注保存、保存失败不污染旧配置、直播缓存更新、刷新合并、搜索重复提交、旧请求竞争、流式回退和超时；浏览器验证包含 320px、390px、桌面、深色模式和未加载 JavaScript 时的原生表单提交。
