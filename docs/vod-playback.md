# 点播播放与原版去广告

电影、电视剧的 HLS 播放通过 `src/lib/vod-playback.ts` 初始化。按照用户要求，去广告已恢复为修改前播放器的原版逻辑。

- 开启“去广告”时，使用共用自定义 HLS 加载器，拦截 `manifest` 和 `level` 的文本响应，按行删除包含 `#EXT-X-DISCONTINUITY` 的内容，包括 `DISCONTINUITY-SEQUENCE`。过滤函数与原版一致，不区分资源站名称或域名。
- 不增加广告路径识别、CUE/SCTE35 推断、分片移除、GAP、广告时间跳转、时间轴压缩或进度映射。播放列表中的 URI、分片时长、密钥、字节范围和其他标签按原版保留，由 hls.js 按原版方式处理分片时间戳。
- 保留“去广告”开关，默认开启，兼容 `enable_blockad` 本地偏好。关闭时使用默认 HLS 加载器；切换时重建播放器并恢复当前进度。
- 播放记录、片头片尾和恢复播放使用播放器进度，不再转换源时间轴和过滤后的时间轴。
- 保留之前独立的点播缓冲优化：关闭低延迟模式，前向缓冲目标 60 秒、最长目标 120 秒、后向保留 30 秒，字节参数为 60 MB。切集先销毁旧 HLS 实例；原生 HLS 回退保持可用。

测试使用真实 hls.js 清单解析器核对原版过滤开关、分片序号、时长、密钥和初始化映射，并检查没有新增的定时 seek。去广告恢复原版行为，不承诺任意源和广告形式均能过滤。
