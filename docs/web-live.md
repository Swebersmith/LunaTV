# 网页直播

在管理面板的直播源设置中开启网页直播，添加可访问的 HTTP / HTTPS M3U 频道列表即可使用。账号配置和 Cloudflare 数据库绑定无需写入 GitHub。

- 默认通过站内代理播放，兼容没有跨域响应头或只有 HTTP 地址的直播源。支持主播放列表、备用音轨、AES 密钥、初始化分片和字节范围请求，保留源地址中的签名参数。
- 支持 MSE 的浏览器使用 hls.js，不支持 MSE 但具备原生 HLS 能力的 Safari / iOS 等浏览器会回退到原生播放。MP4 使用浏览器原生播放；FLV、RTSP、UDP、RTP 和设备不支持的编码需要源端转换为兼容的 HLS，网站本身不做转码。
- 自动播放被浏览器拦截时显示“点击播放直播”。网络故障有有限次数重连，媒体错误尝试恢复；连接或画面长时间停滞会显示重试按钮，并保留频道列表。
- “使用代理重试”可以在当前播放会话中绕过浏览器直连设置，处理源端跨域或网络问题。
- 频道列表在 Worker 内存中缓存五分钟，加载失败时可用“刷新频道”立即重新拉取，播放失败时也可用“刷新频道地址”更新过期地址并保留当前频道。节目单独立按需读取，失败不影响播放。频道浏览、播放、重连、节目单读取不会写入 KV 或 D1；收藏、管理员保存和显式刷新频道数仍按操作保存。
- 切换频道、切换直播源和离开页面都会清理旧播放器、网络恢复定时器和待处理请求。

验证包括播放器生命周期和失败恢复测试、真实 workerd 中的代理与 Range 响应，以及桌面和移动尺寸浏览器中的真实 HLS 视频解码与切台。原生 HLS 分支有自动化测试；Windows 测试环境不能代替实体 iPhone / Safari 的验证。

第三方源失效、地域 / IP 限制、上游鉴权或浏览器不支持的音视频编码仍会影响播放。遇到这些情况应更换可用频道源。
