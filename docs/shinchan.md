# 蜡笔小新专区

首页大海报的「去看小新」进入 `/shinchan`，集中展示电视动画各季、剧场版与合集。点开条目可选择片源和语言版本，再进入原有播放器选集观看；播放记录、收藏和切换片源继续沿用原有功能。

## 目录与匹配

- 剧场版目录包含 1993—2026 年的 34 部长篇作品，其中包括 2023 年的 3DCG 电影，按日本首映年份排序。目录与译名在 `src/lib/shinchan-catalog.ts` 维护。
- 年份参照[官方历史](https://www.shinchan-app.jp/about/index.php)及[新锐动画电影目录](https://www.shin-ei-animation.jp/2016/shinchan/movie/)。2026 年作品参照[电影官方网站](https://shinchan-movie.com/2026/)。只收录标题、年份及用于检索的不同译名，不复制剧情简介或影片文件。
- 电视动画按片源返回的实际季数合并，同一季的数字、中文序号及国语/日语版本归在一起；新增季数无需修改页面。
- 同一电影的不同译名合并展示。电影解说、预告片、无关影片及没有播放条目的结果会被过滤。
- 剧场版合集与外传单独展示，合集的通用集数不会被假定为电影序号，避免跳到错误作品。

## 播放与用量

页面复用已登录用户可用的片源、现有分页搜索和内存搜索缓存。进入专区先检索「蜡笔小新」，仅在没有结果时尝试繁体名称；不在打开页面时逐一搜索全部电影。点开尚未匹配的电影时，才补查该片标题和一个常见译名，关闭窗口会取消客户端请求。加载、网络错误、空结果和没有片源的状态均有提示。

播放链接使用检索结果的真实 `source`、`id`、标题及年份，并带 `returnTo=/shinchan`。目录不把某作品标记为必定可播；实际可用性由现有片源与影片上新情况决定。

专区不新增 KV/D1 写入、定时任务或数据表。只有用户观看后，播放器才按原有规则保存观看进度。目录支持片名/年份筛选、年份排序和「只看已找到片源」，兼容手机布局、深色模式、键盘和 Esc 关闭版本选择。
