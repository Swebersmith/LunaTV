# 蜡笔小新专区

首页的防卫队插画是一处小彩蛋，点击整张海报即可进入 `/shinchan`，集中展示电视动画各季、剧场版与合集。点开条目可选择片源和语言版本，再进入原有播放器选集观看；播放记录、收藏和切换片源继续沿用原有功能。

## 目录与匹配

- 剧场版目录自动合并官方上映历史和 Bangumi 电影条目（含中文译名、日文原名及上映日期），不限制数量或截止年份。`src/lib/shinchan-catalog.ts` 中的 34 部旧作品仅作离线保底；未来新电影无需修改清单或重新部署。同一年多部电影按作品身份分别保存，不按年份强行合并。
- 年份参照[官方历史](https://www.shinchan-app.jp/about/index.php)及[新锐动画电影目录](https://www.shin-ei-animation.jp/2016/shinchan/movie/)。2026 年作品参照[电影官方网站](https://shinchan-movie.com/2026/)。只收录标题、年份及用于检索的不同译名，不复制剧情简介或影片文件。
- 电视动画按片源返回的实际季数合并，同一季的数字、中文序号及国语/日语版本归在一起；新增季数无需修改页面。
- 同一电影的不同译名合并展示。片源中新发现、明确标记为电影/剧场版的作品也会自动加入。电影解说、预告片、无关影片及没有播放条目的结果会被过滤；官方历史中的真人改编记录不会当成新动画电影。
- 剧场版合集与外传单独展示，合集的通用集数不会被假定为电影序号，避免跳到错误作品。

## 播放与用量

打开专区时自动同步目录，并以简体、繁体、日文名称检索当前用户有权限使用的片源。专用分页接口自动跟进各源返回的页数，不受普通搜索默认 5 页限制；客户端最多并行 4 个请求，单源单关键词最多 100 页，超限或部分失败会显示提示。每个 Worker 分页请求只查询一个片源，复用 10 分钟内存搜索缓存。点开尚未匹配的电影时还可补查标题和译名。

专区在前台每 15 分钟自动更新片源、季数与集数；隐藏时停止轮询，返回页面后补查，恢复联网后立即重试。后台更新保留当前页面与筛选状态，不清空清单。官方目录与 Bangumi 资料每 6 小时到期重查，部分失败时 5 分钟后允许重试。同步由正常页面请求触发，不要求站长设置定时任务。电影显示“尚未上映”“已发布、等待片源”和可选播放版本，发布信息与播放可用性分别处理。

播放链接使用检索结果的真实 `source`、`id`、标题及年份，并带 `returnTo=/shinchan`。目录不把某作品标记为必定可播；实际可用性由现有片源与影片上新情况决定。

专区不新增 KV/D1 写入、定时任务、数据表、账号配置或 API Token。公开上映目录使用 Workers Cache API 和纯数据内存缓存；片源结果始终按当前用户权限读取，HTTP 响应为 private/no-store，不在共享缓存中存储用户片源。上游暂不可用时保留上次目录并显示状态，之后自动重试；缓存也不可用时仍展示离线保底。只有用户观看后，播放器才按原有规则保存观看进度。

自动整理依赖公开资料和站长配置的片源：能发现新作不等于已取得播放资源。无需人工查找并维护季数或电影名单，但外部服务未收录、片源未上新或不可用时不能承诺立即可播放。目录支持片名/年份筛选、年份排序和「只看已找到片源」，兼容手机布局和深色模式。
